Before you roll out

  • These run on domain-joined Windows PCs via Tactical RMM. Phones and non-domain devices aren't covered.
  • The install may be run as SYSTEM in Tactical — only the sampling task it creates runs as the signed-in user.
  • Test on one machine and confirm a sample arrives before deploying to a group.
  • Make sure the client has agreed to screen-time monitoring, and that their staff handbook covers it, before turning it on.
